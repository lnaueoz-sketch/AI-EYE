# AI

AI 모델 학습·실험 코드를 두는 폴더입니다. (담당: AI 파트 / 작업 브랜치: `AI`)

## 폴더 구성 (예시)

```
AI/
├─ train/       학습 스크립트, 설정 파일
├─ notebooks/   실험용 Jupyter 노트북
├─ eval/        성능 평가 스크립트·결과 정리
└─ README.md
```

## 규칙

- 학습이 끝난 모델 중 **서비스에 쓸 가중치(`best.pt`)** 는 `backend/models/` 로 옮겨서 백엔드 팀과 공유합니다.
- **데이터셋 원본, 학습 결과 폴더(`runs/`)** 는 용량이 커서 올리지 않습니다. (GitHub는 파일 하나당 100MB 제한)
  → 데이터셋은 Google Drive 등으로 공유하고, 여기에는 받는 방법만 적어 주세요.
